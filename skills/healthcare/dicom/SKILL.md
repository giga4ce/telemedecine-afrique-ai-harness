# DICOM

- Use only anonymized or synthetic DICOM data.
- Keep the POC chain simple: import DICOM, store in Orthanc, expose through DICOMweb, view in OHIF.
- Do not assume a real PACS/RIS integration during the POC.
- Document any test dataset source and anonymization status.
- For network resilience work, record the test conditions and observed recovery behavior.
