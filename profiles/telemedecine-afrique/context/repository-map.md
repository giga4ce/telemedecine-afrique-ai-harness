# Carte du repository produit

- `README.md` : point d'entrée produit.
- `docs/product/` : vision, roadmap et glossaire.
- `docs/poc/` : périmètre et architecture du POC technique.
- `docs/domain/` : contraintes métier et réserves juridiques.
- `docs/target-platform/` : éléments de la plateforme cible, dont les fonctions IA métier futures.
- `docs/sources/` : sources historiques.
- `poc/` : Docker Compose Orthanc/OHIF.
- `data/` : données de test uniquement, anonymisées ou synthétiques.

Le repository produit ne contient plus de contexte LLM maintenu manuellement.
