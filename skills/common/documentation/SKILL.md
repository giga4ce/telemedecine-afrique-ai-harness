# Documentation

- Product docs are canonical for vision, roadmap, POC, domain and legal reserves.
- The harness should point to product docs, not copy them wholesale.
- Mark status clearly: implemented, partial, planned, out of scope.
- Keep README files short and useful as entry points.
- Use French for product documentation.
- Keep AI Harness content separate from future product IA functions.
