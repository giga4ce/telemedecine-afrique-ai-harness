# Workflow

Flux cible :

```text
besoin
-> ticket
-> branche
-> analyse
-> développement
-> tests
-> review
-> PR
```

Convention de branche cible :

```text
feat/TEL-123-short-description
fix/TEL-123-short-description
test/TEL-123-short-description
docs/TEL-123-short-description
chore/TEL-123-short-description
```

Ne pas créer de ticket `TEL-*` fictif. Si aucun ticket vérifié n'existe, rester sur la branche courante ou demander une décision explicite.
