# Frontières du POC

Source canonique : `docs/poc/scope.md` dans le repository produit.

## POC actuel

- Téléradiologie.
- Tchad comme premier terrain de validation.
- Orthanc.
- DICOMweb.
- OHIF Viewer.
- Docker Compose.
- Données DICOM anonymisées ou synthétiques.

- Données patient réelles.
- Comptes rendus médicaux réels.
- RCP.
- Visioconférence.
- Facturation.
- Gestion des vacations.
- PACS/RIS hospitalier réel.
- Production multi-pays.
- Conformité production complète.
- IA diagnostique ou automatisation médicale.
